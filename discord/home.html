Sub Rosa Discord Link

Link your Discord account to your Sub Rosa account, so Discord servers and game servers know who you are.

  1. Add the app to Discord and choose Add to My Apps.
  2. Open it from the App Launcher next to the message box, and press Generate link code.
  3. In Sub Rosa, find {{server_name}} in the server list and join with the code as the password.

Server owners: add the app to your server, then require Sub Rosa account linked on a role under Server Settings, Roles, Links.
